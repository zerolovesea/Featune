# Example data

`adult_income.csv` is a selected and encoded subset derived from the [Adult dataset](https://archive.ics.uci.edu/dataset/2/adult) by Barry Becker and Ronny Kohavi (1996), UCI Machine Learning Repository, [DOI:10.24432/C5XW20](https://doi.org/10.24432/C5XW20). The original dataset is distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). This example changes the column selection and representation; it is provided for tutorials, not as a new source of census data.

`loans.csv` is synthetic example data.
